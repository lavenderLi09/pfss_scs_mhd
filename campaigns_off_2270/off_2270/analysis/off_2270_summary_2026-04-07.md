# `off_2270` 关键结论总结

## 1. 角度归一化修正

- 这组 `off_2270` 的 `x2` 不是直接的弧度，而是按 `2\pi` 归一化。
- 因此：
  - `x2 = 0.0` 对应物理 `theta = 0`
  - `x2 = 0.5` 对应物理 `theta = \pi`
- 所以该模拟覆盖的是完整 `theta = 0 .. \pi`，不是只有北极帽。

## 2. 关键帧 dt 诊断

检查的关键帧：

- `off0000`
- `off0016`
- `off0032`
- `off0064`
- `off0096`
- `off0112`

主结果：

- dt bottleneck 在 6 个关键帧里一直没有换类型
- 它始终位于：
  - 内边界附近：`r ≈ 1.001`
  - 极小 `theta`
  - 主导方向：`phi`
  - 主导类型：`geometry`

代表值：

- `off0000`: `dt_pred_min = 1.046e-06`, `theta_min = 0.00260`, `level = 1`
- `off0016`: `dt_log = 1.089e-06`, `dt_pred_min = 2.536e-07`, `theta_min = 0.00130`, `level = 2`
- `off0112`: `dt_log = 1.162e-06`, `dt_pred_min = 2.375e-07`, `theta_min = 0.00130`, `level = 2`

解释：

- 全局最小 dt 不是被全域最快流动控制
- 而是被极区附近很小的 `r sin(theta) dphi` 所控制
- 所以本质上是球坐标几何 CFL 限制

## 3. 物理量演化是否稳定

从关键帧抽样看，整体演化稳定：

- `dt_log` 在 `~1.09e-06` 到 `1.16e-06` 范围内波动
- `c_s p50` 从 `1.453` 缓慢降到 `1.432`
- `v_A p99` 从 `14.30` 升到 `26.76`
- `c_f,max p99` 从 `14.37` 升到 `26.80`

结论：

- 没有看到明显的数值失稳或 timestep collapse
- 磁相关高尾在增强，但演化是平滑的

## 4. 近日面高速区

对 `r <= 2` 的最大 `|v|` 检查显示：

- 高速区从 `off0016` 到 `off0112` 都集中在同一片角向区域
- 典型位置：
  - `theta ≈ 0.2005`
  - `phi ≈ 0.0859 – 0.0911`

典型量级：

- `off0016`: `|v| = 15.31`, `rho = 7.49e-04`, `|B| = 1.35`
- `off0112`: `|v| = 13.61`, `rho = 3.11e-04`, `|B| = 0.409`

解释：

- 这片高速区更像稳定的局部加速通道 / flux-tube funnel
- 它不是当前全局最小 dt 的主导区域

## 6. 极区 AMR 覆盖

结果见：

- [`amr_theta_cap_summary.csv`](/Users/zhaoyan/Documents/05_heliosphere/pfss_scs_mhd/amrvac_polytropic/off_2270/analysis/amr_theta_cap_summary.csv)

关键结果：

- `theta < 0.5°`
  - `off0016` 起，一旦有 cell 命中，该区域就是 `100% L2`
- `theta < 1°`
  - `L2`: `10.26% -> 25.23%`
- `theta < 2°`
  - `L2`: `18.60% -> 40.29%`
- `theta < 5°`
  - `L2`: `0% -> 35.99%`

从内边界面积看：

- `theta < 2°` 时，`L2` 已覆盖 `66.67%` 的 cap 面积
- `theta < 5°` 时，`L2` 已覆盖 `58.15%` 的 cap 面积

结论：

- 极区越靠近最小 `theta`，越容易被保持在 `L2`
- 而这正好和 dt bottleneck 的位置重合

## 7. 数值判断

当前最明确的数值结论是：

- dt 最危险区一直是极小 `theta` 处的 `phi` 几何瓶颈
- 这个区域后期还被保持在 `L2`
- 所以 “极区小 `sin(theta)` + 极区高 AMR level” 一起把 `C_phi` 顶高了

## 8. 优先优化建议

如果目标是先把 dt 放宽，最有效的第一步不是全域降分辨率，而是：

1. 先限制最小极区帽里的 `L2`
2. 优先针对 `theta < 0.5° / 1° / 2°` 的区域做 refine 限制
3. 如果还不够，再考虑更宽的极区限级
4. 最后才考虑全域性降分辨率

原因：

- dt bottleneck 的位置高度稳定
- 它不是满域随机出现
- 它集中在几何最危险、同时又被维持在 `L2` 的极区小帽

所以，**先限制极区 `L2` 覆盖范围，是当前最对症的数值优化方向。**
