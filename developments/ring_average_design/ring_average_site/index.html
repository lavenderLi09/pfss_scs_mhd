1. 极区 CFL 问题是什么

球坐标里方位向网格尺度为 Δsφ = r sin(θ) Δφ。在靠近极区 (θ → 0, π) 时，sin(θ) 很小，导致 Δsφ 极小，从而把显式时间步长 Δt 卡得很小。 

Δt ≤ C_cfl / max_cells( Σ_d [ c_d / Δs_d ] )

这里如果 cφ / Δsφ 很大，就可能主导限步。Ring-Average 的核心就是把极区的“最薄 φ 单元口径”替换成“chunk 后的有效口径”。

2. Ring-Average 的核心公式

2.1 有效尺度

Δsφ,eff = Nchunk · Δsφ

Nchunk 是在极区沿 φ 合并的 chunk 大小（通常取 2 的幂并受 Nmax 限制）。

2.2 守恒平均

Ū_k = (1 / Nk) · Σ_{i ∈ chunk k} U_i

先在 chunk 上做守恒量平均，再用平均后的状态做界面重构或通量评估。 这样做的目标不是“强行加速波速”，而是改变极区离散口径，避免被最薄小格主导。

2.3 我们当前 V1 的 chunk 规则

ratio = max(1, Δsθ / Δsφ)
k = clamp( floor(log2(ratio)), 0, kmax )
Nchunk = min(Nφ_local, 2^k)

实现中对尺度使用 abs(Δsθ) 与 abs(Δsφ) 以避免符号导致误判。

3. 算法流程（当前实现）

  1. 判断是否位于 spherical 3D 的 φ 重构方向，且在极帽内。
  2. 根据 Δsθ/Δsφ 与 polar_ring_max_chunk 计算 Nchunk。
  3. w (primitive) → wcons (conserved)。
  4. 在每个 φ-chunk 上对 1:nwflux 做守恒平均。
  5. wcons → primitive 写回，再走原 limiter 重构。

这版是 average-then-reconstruct，并未替换原有 limiter。

4. 在 AMRVAC 中我们改了哪些位置

参数定义

src/mod_global_parameters.t
  logical :: polar_ring_evolve

输入参数

src/io/mod_input_output.t
  /paramlist/ ... polar_ring_evolve
  polar_ring_evolve = .false. (default)

CFL 路径

src/mod_dt.t
  get_courant_ds():
    Δsφ -> Δsφ,eff = Nchunk * Δsφ

重构路径

src/mod_finite_volume.t
  reconstruct_LR():
    call apply_polar_ring_average_primitive(...)

5. 参数开关

&paramlist
  polar_ring_average          = .true.   ! 开启 CFL 有效口径
  polar_ring_evolve           = .true.   ! 开启重构前平均
  polar_ring_theta_cap_north  = 0.10d0   ! 北极帽(弧度)
  polar_ring_theta_cap_south  = 0.00d0   ! 南极帽(弧度)
  polar_ring_max_chunk        = 32
/

如果只想做 CFL 放宽而不改演化路径，可将 polar_ring_evolve = .false.。

6. 我们这组实验里看到的结果

  • 在 baseline 与 pole-AMR2 测试里，RING_DEBUG 均显示 ring 命中，且 dirmax_phi 明显下降。
  • 但全局最小 dt 仍常由径向项主导（dirmax(1) 最大），因此 dt 不一定提升。
  • 这并不代表 ring 无效，而是说明这批状态下真正 bottleneck 不在 φ 项。

7. CFL-only 与 Full-path 的区别

CFL-only

只改 dt 判据口径，不改界面状态。等价于“允许走更大步”，数值解演化本身不变。

Full-path V1

在极区 φ 重构前先做 chunk 平均，再用原 limiter（当前 case 为 vanleer/PLM） 重构。会影响演化，但仍是简化版。

8. 当前局限与下一步

  • 目前只覆盖 non-staggered / cell-centered 路径。
  • chunk 平均是块内局部实现，不是全局 ring 通信版本。
  • 重构目前是“先平均，再原 limiter”，尚未做完整 ring-PLM/PPM 面状态构造。
  • 下一步可做：全局 ring 分组、CT 路径兼容、守恒通量级一致性实现。
